3. Data Quality & Cleaning Rules

  • Header Hunting: Scripts must dynamically find the header row. It varies from Row 1 to Row 3.
  • Matrix Unpivoting: ETAT ASSEMBLEES BONAMOUSSADI is a matrix. It needs to be "melted" (Unpivoted) to extract (Assembly, Member_Count) pairs.
  • Multiple Tables: Listes Assemblées Bonaberi.xlsx contains multiple disconnected tables. ETL must split by blank lines or "ASSEMBLEE..." titles.
  • Boolean Logic: Columns like "Baptême" often contain "Oui", "Non", "X", or are blank. Rule: IF val IN ['Oui', 'X', 'Yes'] THEN true ELSE false.

4. Proposed Schema Update (DDL)

Action Required: To ingest the provided Excel files, we MUST add a `members` table. The `profiles` table is only for Leaders who log in.

-- NEW TABLE: Members (The people in the pews)
CREATE TABLE public.members (
    id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    full_name text NOT NULL,
    phone text,
    birth_year int,
    conversion_year int,
    is_baptized boolean DEFAULT false,
    
    -- Link to Structure
    center_id uuid REFERENCES public.centers(id),
    house_church_id uuid REFERENCES public.house_churches(id),
    
    -- Status
    status text DEFAULT 'active', -- e.g. active, visitor, child
    notes text,
    created_at timestamp DEFAULT now()
);

-- RLS for Members
ALTER TABLE public.members ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Center Leads view/edit their members" ON public.members 
FOR ALL TO authenticated
USING (
  public.get_my_role() = 'center_lead' AND 
  center_id = public.get_my_center_id()
);

5. Migration Strategy & Pipeline

Phase 1: Structure Seeding

  1. Extract Centers: Read Effectifs...xlsx -> Insert unique "EGLISES" into `public.centers`.
  2. Extract House Churches: Scan headers of Bonaberi/Cogefar files -> Insert into `public.house_churches` linked to respective Centers.

Phase 2: Member Import

  1. Iterate Files: Run Python script to parse member lists.
  2. Lookup IDs: Match "Assemblée de Maison" name to `public.house_churches.id`.
  3. Insert Members: Load ~500 rows into `public.members`.

Phase 3: Historical Stats

  1. Create Reports: Generate "Annual Report 2020", "2021", etc., in `public.reports`.
  2. Load Stats: Read Effectifs...xlsx columns (EoY 2020...) -> Insert into `stats_people`.
