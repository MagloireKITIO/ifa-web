Frontend Database Integration Guide

Comprehensive reference for data variables, types, and database mappings.

v1.0.0 | Updated: 2026-02-05

1. Users & Profiles (profiles)

TypeScript Interface: User

DB Table: public.profiles

Variable Name Data Type Required DB Mapping Description & Usage
id string (UUID) Yes id Primary Key. Linked to Supabase Auth ID.
email string Yes email User's email address.
full_name string Yes full_name Display name of the user.
role UserRole Yes role Enum: 'admin', 'center_lead', 'house_lead', 'viewer'. Controls permissions.
center_id string | null Optional center_id FK to centers. Required for 'center_lead'.
house_church_id string | null Optional house_church_id FK to house_churches. Required for 'house_lead'.
avatar string Optional avatar URL to avatar image.
Frontend Usage: Use useAuth() hook to access the current user's profile. The profile is automatically fetched and typed as User.

2. Organization Structure

Centers (centers)

Variable Name Data Type Required DB Mapping Description

zone_id string Yes zone_id FK to zones.

Variable Name Data Type Required DB Mapping Description

name string Yes name Name/Code of the house church.
center_id string Yes center_id Parent center ID.
host_name string Optional host_name Name of the host family/person.

5. API Integration & Query Examples

Fetching User Reports


// Example: Fetching full reports with joined statistics
const { data, error } = await supabase
  .from('reports')
  .select(`
    *,
    stats_financial(*),
    stats_people(*),
    stats_family(*),
    stats_activities(*),
    reporting_periods(*),
    centers(name),
    house_churches(name)
  `)
  .eq('submitted_by', userId);

Inserting a New Report


// 1. Create the base report
const { data: report, error } = await supabase
  .from('reports')
  .insert({
    period_id: periodId,
    center_id: centerId,
    submitted_by: userId,
    status: 'draft'
  })
  .select()
  .single();

// 2. Insert statistics (using the returned report.id)
await supabase.from('stats_people').insert({
  report_id: report.id,
  attendance_total: 150,
  new_converts: 2
});
