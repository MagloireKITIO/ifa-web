
# IFA Data System: Non-Technical Overview

## 1. Introduction
This document explains how the Integrity For All (IFA) data system works in plain language. It is designed for church leaders, administrators, and stakeholders who need to understand *what* data we collect and *how* it connects, without getting bogged down in technical database jargon.

**Our Goal**: To simplify the monthly reporting process while ensuring we capture all the vital statistics needed for the Annual Report.

---

## 2. Who is involved? (Users & Roles)

This table shows who uses the system and what they can do.

| Role (Who?) | Responsibilities (What they do) | Access Level (What they see) |
| :--- | :--- | :--- |
| **Admin** | Oversees the entire system. | **Everything**. Can see all reports from all Centers and House Churches. |
| **Center Leader** | Manages a specific Worship Center (e.g., Akwa). | **Limited**. Can only see data for *their* Center and the House Churches under it. |
| **House Leader** | Leads a House Church/Cell Group. | **Strictly Limited**. Can only see and submit reports for *their* specific House Church. |
| **Viewer** | Partners or Guests. | **Read-Only**. Can view dashboards but cannot change any numbers. |

---

## 3. How the Organization is Structured

Think of the system like a family tree. Here is how the locations connect:

| Level | Description | Example |
| :--- | :--- | :--- |
| **1. Region** | The largest area we cover. | Littoral |
| **2. Zone** | A district within the region. | Douala Nord |
| **3. Center** | The main church building/location. | Center Akwa |
| **4. House Church** | Small groups meeting in homes. | Cellule Espoir (Bonapriso) |

**Key Rule**: Every **House Church** must belong to one **Center**. Every **Center** belongs to one **Zone**.

## 4. What Data Do We Collect? (The 4 Pillars)

Instead of one giant confusing form, we organize data into four clear categories (Pillars). This matches how you already think about church life.

### Pillar 1: Money (Finance)
*Who sees this? Mostly Center Leaders & Admins.*

| Information | Definition | Why we need it? |
| :--- | :--- | :--- |
| **Tithes (Dîmes)** | 10% contributions. | To track faithful stewardship. |
| **General Offerings** | Sunday basket collections. | For day-to-day operations. |
| **Event Offerings** | Special seeds sown during conferences. | To fund specific events like "River of Life". |
| **Mission Support** | 10% deducted for missions. | To support the "Investir pour le Royaume" goal. |

### Pillar 2: People (Growth)
*Who sees this? Everyone (House & Center Leaders).*

| Information | Definition | Annual Report Goal |
| :--- | :--- | :--- |
| **Headcount** | How many Men, Women, Children attended? | "Effectifs des disciples actifs" |
| **New Converts** | People who gave their life to Christ. | "Gagner les perdus à Christ" |
| **First Timers** | Visitors coming for the first time. | Tracking outreach effectiveness. |
| **Churn (Lost)** | Members who stopped coming. | "Mobilité / Défaut d'intégration" |

### Pillar 3: Family Life
*Focus: Social stability and milestones.*

| Information | Definition | Why we need it? |
| :--- | :--- | :--- |
| **Marriages** | Number of weddings celebrated. | "Renforcer la famille" |
| **Engagements** | Number of official fiançailles. | Tracking future families. |
| **Births** | New babies born in the church. | Celebrating life. |
| **Counseling** | Couples receiving pastoral advice. | Ensuring spiritual health. |

### Pillar 4: Impact (Activities)
*Focus: What we DO outside the church walls.*

| Information | Definition | Annual Report Goal |
| :--- | :--- | :--- |
| **Training** | People completing Bible School/Training. | "Equiper les saints" |
| **Social Actions** | Meals given, charity work. | "Luire dans la société" |
| **Youth Mentoring** | Young people in mentorship programs. | "Encadrement des Jeunes" |

## 5. How the Monthly Report Works

This is the step-by-step process of how data moves from a leader's phone to the final Annual Report.

| Step | Action | Who does it? | What happens in the system? |
| :--- | :--- | :--- | :--- |
| **1. Open Period** | Admin says "Report for Jan 2026 is open". | **Admin** | The system creates blank forms for everyone. |
| **2. Data Entry** | Leaders fill in the 4 Pillars (Money, People, etc.). | **Center/House Leads** | Data is saved as "Draft". |
| **3. Submission** | Leader clicks "Submit". | **Center/House Leads** | The report is locked. No more changes allowed. |
| **4. Review** | Admin checks the numbers. | **Admin** | Status changes to "Approved". |
| **5. Analysis** | The system adds up all numbers. | **System (Automatic)** | The Dashboard updates with total Growth, Income, etc. |

## 6. Frequently Asked Questions (FAQ)

**Q: Do I need to list every single person's name?**
A: **No.** For the Monthly Report, we only need numbers (e.g., "50 Men", not a list of 50 names). This keeps it fast and simple.

**Q: Can a House Leader see the Center's finances?**
A: **No.** The system is smart. It hides sensitive financial data from House Leaders. Only Center Leaders and Admins can see financial totals.

**Q: What if I made a mistake after submitting?**
A: You must contact an Admin. They can "Unlock" your report so you can fix it. This prevents accidental changes to historical records.
